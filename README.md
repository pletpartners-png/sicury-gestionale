# Sicury Turni — prototipo

Prototipo dimostrativo del gestionale turni di Sicury Servizi.

**Non e' il sistema di produzione.** I dati sono inventati, restano nel browser
di chi apre la pagina e non esiste autenticazione lato server. Serve a validare
i flussi con il cliente prima dello sviluppo vero.

Separato dal sito pubblico: repository distinto, sottodominio distinto,
nessun collegamento nelle due direzioni.
